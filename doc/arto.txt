INTRODUCTION						*arto-introduction*

*arto.vim* is a Neovim plugin to open Markdown files in Arto (v0.15.0+),
a Markdown reader application. Supports macOS and Linux.

https://github.com/arto-app

Requirements: Neovim 0.10+


=============================================================================
INTERFACE						*arto-interface*

-----------------------------------------------------------------------------
VARIABLE						*arto-variable*

*g:arto_path*
	Path to the Arto application.

	macOS:
	  Default: "/Applications/Arto.app"
	  The plugin resolves the executable as:
	    {g:arto_path}/Contents/MacOS/arto

	Linux:
	  Default: "arto"
	  The plugin uses {g:arto_path} directly as the executable
	  path.

	Examples (Vimscript):
>vim
	let g:arto_path = '/Applications/Arto.app'  " macOS
	let g:arto_path = '/usr/local/bin/arto'     " Linux
<
	Examples (Lua):
>lua
	vim.g.arto_path = '/Applications/Arto.app'  -- macOS
	vim.g.arto_path = '/usr/local/bin/arto'     -- Linux
<

-----------------------------------------------------------------------------
COMMAND							*arto-command*

:Arto [{path} ...]					*:Arto*
	Open one or more Markdown files in Arto.

	Each {path} is expanded as a Vim expression (e.g. |expand()| is
	applied) and passed to Arto.

	If no {path} is given, the current file (|%:p|) is used.

	Examples:
>vim
	:Arto
	:Arto %:p
	:Arto ~/Documents/notes.md
	:Arto file1.md file2.md file3.md
<

:ArtoVersion						*:ArtoVersion*
	Show the version of the Arto executable.


-----------------------------------------------------------------------------
FUNCTION						*arto-function*

Lua module `arto` exposes the following functions:

require('arto').open([{expr} ...])			*arto.open()*
	Open one or more files in Arto.

	If no argument is given, the current file is used.
	Each {expr} is expanded via |expand()| and passed to Arto.

require('arto').version()				*arto.version()*
	Display the version of the Arto executable.
